# ADR-0010 — SAF-T 2.1 upstream and versioning

Status: Accepted

## Decision

Dolibarr DK targets Danish SAF-T **2.1**.

The technical source of truth is Erhvervsstyrelsen's Standard Filformater GitLab repository.

Pinned upstream baseline:

- repository: `https://git.erst.dk/standard-filformater/standard-filformater.git`
- commit: `ea9a4b5704c7a0e9646b0d3b928a59089d71cf0e`
- XSD: `SAF-T/XSD/Danish_SAF-T_Financial_Schema_v_2_1.xsd`
- official example: `SAF-T/XML_examples/SAF-T v. 2.1.xml`
- XML namespace: `urn:StandardAuditFile-Taxation-Financial:DK`
- `AuditFileVersion`: `2.1`
- standard chart version accepted for the 2027 target: `20260101`

## Architecture

```text
Dolibarr
   |
   v
Canonical Accounting Model
   |
   v
SAF-T 2.1 exporter
   |
   v
XML
   |
   v
Official ERST XSD validation
```

SAF-T XML generation must not query Dolibarr tables directly.

## Upgrade policy

An upstream ERST commit change is not consumed automatically.

A proposed upstream update must:

1. show the upstream diff,
2. run the generated XML against the new XSD,
3. run canonical/accounting regression tests,
4. document schema or mapping changes,
5. update this ADR/registry pin through review.

## Important schema observations

The official 2.1 XSD filename and examples identify the target as 2.1, while the root `xs:schema` metadata currently still contains `version="2.0"`. Dolibarr DK does not rewrite or reinterpret that upstream metadata; the pinned official artefact is used unchanged.
